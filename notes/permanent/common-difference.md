The **Common Difference** is the fixed amount added to each term of an [Arithmetic Sequence](arithmetic-sequence.md) to get the next one, usually written $.

You can find it by subtracting any term from the one after it:  = u_{n+1} - u_n$. For example, in 1, 7, 13, 19, ... the common difference is 6. It can be negative, in which case the sequence decreases.
