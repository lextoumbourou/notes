**Language Agent Tree Search (LATS)** is a framework which improves reasoning capabilities of language models by integrating them into a tree search algorithm. They adapt [Monte Carlo Tree Search](monte-carlo-tree-search.md), which is a successful algorithm in [Reinforcement Learning (RL)](reinforcement-learning.md).
