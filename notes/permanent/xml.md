**XML** (eXtensible Markup Language) is a markup language that defines rules for encoding documents in a format that is supposed to be both machine-readable and human-readable. It allows for defining documents with [Semantic Content](semantic-content.md).

There are two main languages for querying XML documents:
* [XSLT (eXtensible Stylesheet Language Transformations)](xslt-extensible-stylesheet-language-transformations.md)
* [XQuery](xquery.md)
