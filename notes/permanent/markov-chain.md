**Markov Chain** is a stochastic process that moves between a set of states, where the probability of moving to the next state depends only on the current state (the [Markov Property](markov-property.md)). It's described by the set of states and a transition matrix of probabilities between them.

Probabilistic counterpart of [Finite Automaton](finite-automaton.md).

A [Markov Decision Process (MDP)](markov-decision-process.md) extends a Markov chain with actions and rewards. See also [Markov Chain Sampling](marvok-chain-sampling.md).
