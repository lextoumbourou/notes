A **Digital Signature** is a technique from [Cryptography](cryptography.md) which employs [Asymmetric Cryptography](asymmetric-cryptography.md) to allow people to sign a message using a private key, which can be verified from the public key. Many digital signature algorithms utilise [RSA](rsa.md) for signing messages.
