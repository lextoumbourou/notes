**Encryption** is the process of converting readable data ([Plaintext](plaintext.md)) into an unreadable form ([Ciphertext](ciphertext.md)) using an algorithm and a key, so that only someone with the right key can read it. The reverse process is [Decryption](decryption.md).

There are two main types:

* [Symmetric Cryptography](symmetric-cryptography.md): the same key is used to encrypt and decrypt.
* [Asymmetric Cryptography](asymmetric-cryptography.md), also known as [Public Key Encryption](public-key-encryption.md): a public key is used to encrypt, and a private key to decrypt.

See [Cryptography](cryptography.md).
