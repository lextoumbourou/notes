A **REST API** is a network API that follows the Representational State Transfer architectural style. It identifies resources with URLs and uses standard HTTP methods, such as `GET`, `POST`, `PUT` and `DELETE`, to operate on them. Unlike [JSON-RPC](json-rpc.md), REST does not usually represent operations as named method calls to one endpoint.
