Scalable Vector Graphics (SVG) is an open XML-based file format for web graphics, that enables resolution-independent images that can be styled with CSS and manipulated with JavaScript. Originally developed by the World Wide Web Consortium (W3C) in 1999, SVG has become the standard for vector graphics on the web, allowing designers to create everything from simple icons to complex animations while maintaining minimal file sizes. All modern web browsers now support SVG natively, making it possible to embed vector graphics directly into HTML code or use them as standalone files that can be dynamically modified through programming.
