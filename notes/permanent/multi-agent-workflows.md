**Multi-Agent Workflows** are [Agentic Workflow](agentic-workflow.md) where several [AI Agents](ai-agents.md), usually [Large Language Models](large-language-models.md) each prompted with a specific role, collaborate on a task by passing work between each other.

For example, [MetaGPT](metagpt.md) simulates a software company, with agents acting as product manager, architect and engineer.

See [Multi-Agent Systems](multi-agent-systems.md).
