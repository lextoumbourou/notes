**Computer-Aided Detection (CADe)** is software that helps clinicians find possible abnormalities in medical images. For example, a CADe system might mark suspicious regions on a [Mammograms](mammogram.md) for a radiologist to review.

CADe answers "where should I look?". It's usually paired with [Computer-Aided Diagnosis (CADx)](computer-aided-diagnosis.md), which characterises a finding once it's been located, for example estimating whether a lesion is benign or malignant. In both cases the system supports the clinician rather than replacing them.
