The **Derivative** of a function refers to the rate of change with respect to an input variable at a given point. The derivative gives the slope of the tangent line to the function at a given point. Usually denoted as $f'(x)$ or $\frac{dy}{dx}$.

When we have a function with multiple variables, we call it the [Gradient](gradient.md) which is the generalisation of the derivative for functions with multiple input variables.
