**Project Reactor** is a library for building non-blocking, [Reactive APIs](reactive-apis.md) applications on the JVM, based on the Reactive Streams specification.

It provides two main types for working with asynchronous streams of data: `Mono`, which emits 0 or 1 values, and `Flux`, which emits 0 to N values.

It's the foundation of Spring WebFlux.
