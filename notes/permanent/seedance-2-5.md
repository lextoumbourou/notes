[Seedance 2.5](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5) is ByteDance Seed Team's audio-video generation and editing model, announced in August 2026. It builds on Seedance 2.0's multimodal audio-video joint-generation architecture.

Here's the announced stats:

| Capability | Seedance 2.5 claim |
| --- | --- |
| Native generation length | Up to **30 seconds** of audio-video in one pass |
| Change from Seedance 2.0 | **2×** longer single-pass generation, from 15 to 30 seconds |
| Longer output | Multiple rounds of extension, intended to create multi-minute videos while preserving subject, environment, pacing and audiovisual continuity |
| Image references per generation | Up to **30** |
| Video references per generation | Up to **10** |
| Audio references per generation | Up to **10** |
| Total reference items | Up to **50** mixed assets in one generation |
| Editing control | Timestamp-level prompting and targeted edits to characters, actions or plot elements while retaining surrounding continuity |
| Other editing features | Green-screen, camera-perspective and reference-based editing |

It's rolling out through **Jimeng AI**, **Doubao Pro** and other platforms at announcement ByteDance says **BytePlus ModelArk API** access is coming soon. Pricing, rate limits, licensing and public API timing were not stated in the launch post.
