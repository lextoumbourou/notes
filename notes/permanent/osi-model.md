The **OSI Model** (Open Systems Interconnection model) is a conceptual model, published by the International Organization for Standardization (ISO), that splits network communication into seven layers:

1. Physical
2. Data Link
3. [Network Layer](network-layer.md)
4. [Transport Layer](transport-layer.md)
5. Session
6. Presentation
7. [Application Layer](application-layer.md)

Each layer provides services to the layer above it and relies on the layer below it. In practice, the internet runs on [TCP/IP](tcp-ip.md), which merges the top three layers into one. See [TCP/IP Five-Layer Network Model](tcp-ip-5-layer-network-model.md).
