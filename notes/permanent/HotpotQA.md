**HotpotQA** is a dataset for question answering from paper [HotpotQA: A Dataset for Diverse, Explainable Multi-hop Question Answering](hotpotqa-a-dataset-for-diverse-explainable-multi-hop-question-answering.md).

It contains around 113k question-answer pairs based on Wikipedia, where answering each question requires reasoning over more than one supporting document (multi-hop reasoning).
