I think a lot of us have a sense that we could be doing more with our agents and LLMs. I'm particurlary interested in how much additional knowledge I learn and retain about my work, and about the world generally.

I'm interested in not only preventing [AI-Induced Cognitive Atrophy](ai-induced-cognitive-atrophy.md), but actually converting knowledge of the LLMs into my own knowledge.

Since I'm an MLE-specialised software developer, I'd like to retain not only things relevant to my job, but I'd also like to retain anything that I might need during an interview.

A few examples are things like, how the [Transformer](transformer.md) architecture works. How [Backpropagation](backpropagation.md) works. Making sure I understand fundemental concepts like [Principal Component Analysis](principal-component-analysis.md) and certain statitics concepts, like [Confidence Intervals](Confidence%20Intervals.md).

## Learn by teaching

So far, the absolute best way I've found for trying to learn something, is to try to teach it. That's what this blog is really. Typically,after I learn something, I'll try to retain it by figuring out how to summarise it in a way that I'd like someone to have explained it to me. Making the blog posts public also forces me to add a level of polish that I wouldn't otherwise add with just private notes.

## Daily revision

Every day, as part of my morning routine, my agent suggests 2 topics to test me on. There are a couple of different revision types, all guided by an LLM.

1. Question answering
2. Fill in the blanks with code.
3. Essay writing

For my revision skill, I have a Markdown file that links to all the other topics that I want to remember forever.

I have a skill that I call daily, which picks two concepts to retain.

## Learning System

I'll typically read with a pen and paper, and either write notes as I go, if the material is dense, or summarise at the end of each milestone like a chapter. I'll publish my notes to this blog, and take out any ideas that I really like into their own post.

These notes get turned into revision items.
