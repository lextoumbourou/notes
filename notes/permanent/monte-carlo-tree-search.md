**Monte Carlo Tree Search** or **MCTS** is an algorithm used for decision-making in game theory, which combines random sampling of possible moves with a tree structure to identify optimal actions. It balances exploration and exploitation by simulating many possible future outcomes and using the results to guide the search toward the most promising strategies.
