**Single-Agent Architectures** are agent designs in which a single model does all the reasoning, planning and tool use itself, without other agents providing feedback.

See [Single-Agent Systems](single-agent-systems.md), and compare with [Multi-Agent Architectures](multi-agent-architectures.md).
