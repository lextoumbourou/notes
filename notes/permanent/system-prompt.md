A **System Prompt** is a set of instructions given to a [Large Language Models](large-language-models.md) before the conversation starts, which sets its behaviour for the whole interaction, such as its role, tone, rules and the tools it can use.

Users usually don't see it, and it's treated separately from the user's messages. It's a common place to set a [Persona](persona-prompt-engineering.md). See [Prompt Engineering](prompt-engineering.md).
