**Spearman's rank correlation** ($\rho$) measures how well the ranking of one variable matches the ranking of another, using only the order of values rather than their exact magnitudes. In evaluation-metric papers it checks whether an automatic metric ranks outputs in the same order humans do, which is why it, alongside Kendall's $\tau$, is a standard way to report agreement with human judgment.
