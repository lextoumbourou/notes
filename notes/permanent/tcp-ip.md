Protocol stack used on the internet. Standardised by IETF (Internet Engineering Task Force).

Originally conceptualised with 4 layers, but the 5-layer model emerged later as a hybrid between the TCP/IP and OSI models.

Can be considered an implementation of the [OSI Model](osi-model.md).
