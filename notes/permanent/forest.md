A **Forest** is an undirected graph with no cycles. Another way to say it: a forest is a collection of disjoint trees, where each connected component is a tree. See [Acyclic Graph](acyclic-graph.md) and [Undirected Graphs](undirected-graphs.md).

A single tree is a forest with one component. A forest with $n$ vertices and $k$ connected components has exactly $n - k$ edges.

See [Graph Theory](graph-theory.md).
