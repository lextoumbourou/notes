The **Link Layer** (also called the data link layer) is the layer of a network model responsible for moving frames of data between devices that are directly connected on the same local network.

See [TCP/IP Five-Layer Network Model](tcp-ip-5-layer-network-model.md)

It sits above the [Physical Layer](physical-layer.md), which sends the raw bits over a medium, and below the [Network Layer](network-layer.md), which routes packets between networks. Devices at this layer are identified by MAC addresses, and common link layer protocols include Ethernet and Wi-Fi (IEEE 802.11).
