A **Linear Data Structure** is a data structure where elements are arranged in a sequence, so each element has one predecessor and one successor (except the first and last).

Examples include an [Array](array.md), [Linked List](linked-list.md), [Stack](stack.md) and [Queue](queue.md).

In contrast, non-linear data structures like a [Binary Tree](binary-tree.md) or a graph can connect an element to several others.
