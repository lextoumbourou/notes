**AgentArch** compares agent architectures on enterprise tasks, varying orchestration, prompt implementation, memory and thinking tools. It reports model-specific architecture preferences.

Source: [AgentArch: A Comprehensive Benchmark to Evaluate Agent Architectures in Enterprise](https://arxiv.org/abs/2509.10769v2).
