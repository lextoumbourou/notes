**Tool Documentation** is the description of a tool given to an LLM agent so it can decide when and how to call it. It usually includes the tool's name, what it does, its parameters and their types, and sometimes usage examples.

Because the model only knows about a tool through its documentation, clear and accurate descriptions matter a lot for reliable [Tool Use](tool-use.md).
