**Polynomial Time** describes an algorithm whose running time is bounded by a polynomial in the size of its input.

Polynomial refers to an exponent with a constant $k$: $O(n^k)$

For example, $O(n)$, $O(n^2)$ and $O(n^3)$ are all polynomial time, whereas $O(2^n)$ (exponential time) isn't, since the input size is in the exponent.

Problems that can be solved in polynomial time form the complexity class P, and are generally considered tractable. See [Big-O Notation](big-o-notation.md).
