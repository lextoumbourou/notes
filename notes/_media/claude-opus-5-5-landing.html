01 · The claimsWhat Anthropic says, and what a demo can show

Anthropic's claim

40%

cheaper than Opus 5 on typical workloads at default settings. The figure includes using fewer tokens per task, so it is not a guaranteed discount on every request; savings depend on the workload.

Anthropic also says Opus 5.5 approaches Claude Fable 5.1 on most work, with lower running costs.

The source article's demo

The original article includes a small example that makes one request without caching. It illustrates an API call. A single request cannot verify the benchmark results or the 40% savings figure, and no test results from it are reported here.

Treat vendor figures as vendor figures until you measure your own workload.

02 · AvailabilityWhere it runs, and how it thinks

Platforms
Claude, the Claude API, AWS, Google Cloud and Microsoft Azure (as of 23 September 2026)
API identifier
claude-opus-5-5
Modalities
Text and image input, text output, tool use
Limits
1M-token context window; 128K maximum output tokens
Thinking
Adaptive thinking always on; default effort medium

The two limits are different ceilings, not a promise of 1M input tokens plus 128K output in every request. Effort is adjustable, but there is no separate non-thinking mode; the model still decides how much reasoning each request needs. Model documentation

Effort settings

Default evaluation uses adaptive thinking at max effort, averaged over five trials. Terminal-Bench 4.0 uses xhigh. Both are higher than the API default of medium.

Safeguards on

Launch results include production safeguards, with fallback models handling some restricted tasks.

Not a clean sweep

The same table puts GPT-6 Astra ahead on Terminal-Bench-Science 0.1 and AutomationBench. Other developers' results use their own published setups, not an identical coding harness.

Limitation

Despite improved prompt-injection resistance overall, the system card reports Opus 5.5 is more susceptible to malicious instructions hidden inside text a user pastes into their own message. Better benchmarks do not remove the need to separate instructions from untrusted content.
